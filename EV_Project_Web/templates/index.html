Have questions about the EV Analytics Dashboard?

Find answers to common questions related to electric vehicle charge, range analysis, and dashboard usage.

What is the purpose of the EV Analytics Dashboard?

The EV Analytics Dashboard is designed to provide interactive insights into electric vehicle charging behavior, driving range, pricing, and sustainability metrics using data visualization.

What kind of data is used in this project?

The project uses a structured EV dataset containing information such as vehicle brand, model, battery capacity, range, charging type, price, and CO₂ savings.

How is the dashboard created and visualized?

The dashboard is built using Tableau Public for visualization and embedded into a Flask-based web application for seamless user interaction.

Do users need to register to access the dashboard?

Yes, users can register through a simple OTP-based registration interface to access the EV analytics dashboard.

What insights can users gain from this platform?

Users can analyze average driving range, charging efficiency, price comparisons, brand-wise performance, and environmental impact of electric vehicles.

Is this project scalable for future enhancements?

Yes, the platform can be extended with real-time data sources, cloud storage, predictive analytics, and advanced machine learning models in the future.
